Java H2 Database Swing

Игра на Arduino

Создание игры "Змейка" на базе Arduino Uno с использованием светодиодной матрицы 8x8 и кнопок управления. Разработаны несколько игровых режимов, система подсчета очков и таблица рекордов.

C++ Arduino Электроника

MASM32 WinAPI Assembler

Персональный сайт-портфолио

HTML5 CSS3 JavaScript

Python Pandas Matplotlib
